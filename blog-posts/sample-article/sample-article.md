# My First Dev.to Article

This is a sample article demonstrating how to publish content to dev.to directly from GitHub.

## Introduction

Using GitHub to manage your dev.to articles has several benefits:
- Version control for your content
- Automated publishing via GitHub Actions
- Collaboration with others through pull requests
- Single source of truth for your articles

## Code Example

```javascript
function greet(name) {
  return `Hello, ${name}!`;
}

console.log(greet('Dev.to Reader'));
```

## Conclusion

This workflow allows you to write your content in markdown, store it in GitHub, and automatically publish it to dev.to!
